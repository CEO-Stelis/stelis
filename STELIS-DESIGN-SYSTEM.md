# STELIS DESIGN SYSTEM v1

## Philosophy

STELIS must feel like:

- Apple
- Linear
- Stripe
- Notion

Premium.
Simple.
Fast.
Trustworthy.

Never cluttered.
Never noisy.
Never complicated.

A restaurant owner should understand the screen in less than 3 seconds.

---

# Fibonacci Design Rule

STELIS uses Fibonacci proportions whenever practical.

Sequence:

8
13
21
34
55
89
144
233

These numbers define:

- Typography
- Spacing
- Layouts
- Card proportions
- Visual hierarchy

# Dashboard Grid

Golden Ratio:

1 : 1.618

Examples:

61.8% / 38.2%

38.2% / 61.8%

Cards should feel visually balanced.

---

# Card Design

Every card must have:

- Clear title
- One primary purpose
- One key action

Avoid mixing multiple ideas inside one card.

Cards should feel calm.

---

# Buttons

Primary:

Navy background
White text

Secondary:

White background
Navy border

Danger:

Red background
White text

Buttons should feel substantial and easy to press.

---

# Forms

Rules:

- Minimal fields
- Large inputs
- Clear labels
- No unnecessary instructions

Every form should feel effortless.

---

# STELIS Dashboard Architecture

Priority Order:

1. Sales
2. Inventory
3. Cash
4. Payments
5. AI Recommendations

The owner should always understand:

What happened?
What matters?
What should I do next?

Within 3 seconds.

---

# Design Principle

Every screen must answer:

What happened?
Why?
What should I do now?

If a screen does not answer those questions,
it should be redesigned.
