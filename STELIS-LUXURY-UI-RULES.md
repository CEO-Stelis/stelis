# STELIS LUXURY UI RULES

## Core Philosophy

STELIS should feel like:

- Apple
- Bloomberg
- Porsche
- Rolex
- Tom Ford

Never like:

- A startup dashboard
- A crypto website
- A gaming UI
- A colorful SaaS product

---

## Design Goal

The owner should feel:

- Calm
- In control
- Intelligent
- Wealthy
- Ahead of problems

The interface should reduce anxiety.

Never create noise.

---

## Color System

### Navy

Purpose:

- Structure
- Navigation
- Identity

Primary Brand Color.

---

### White

Purpose:

- Reading
- Clarity
- Space

Primary Interface Color.

---

### Green

Purpose:

- Success
- Positive trends
- Healthy status

Green must be rare.

Green must be meaningful.

Never use green as decoration.

---

### Red

Purpose:

- Risks
- Warnings
- Attention Required

Never use red for positive metrics.

Never use red for decoration.

---

### Cyan

Purpose:

- Interaction
- Links
- Active states
- Charts

Never dominant.

Only supportive.

---

## Typography

### Serif

Used for:

- Health Status
- Important Numbers
- Cash
- Scores
- Executive Headlines

Purpose:

Create prestige and confidence.

---

### Sans Serif

Used for:

- Labels
- Navigation
- Explanations
- Actions

Purpose:

Create clarity and speed.

---

## Information Hierarchy

Every screen should answer:

1. Am I okay?
2. What requires attention?
3. What should I do next?

Only after those questions:

4. Details
5. Reports
6. Analytics

---

## Dashboard Philosophy

STELIS is not a dashboard.

STELIS is a Morning Brief.

The owner should understand the business in less than 30 seconds.

---

## Color Distribution

Target:

85% White + Navy

10% Green

3% Red

2% Cyan

---

## Luxury Rule

If a color, icon, chart, animation, or card does not help a restaurant owner make a decision faster, it does not belong in STELIS.

---

## Simplicity Rule

Before adding an element:

Ask:

Does this improve a decision?

If not:

Remove it.

---

## STELIS Rule

Answers before data.

Decisions before reports.

Clarity before features.

Trust before growth.
